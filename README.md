A meme about an AI agent that has gone rogue — it took "turn it off and on
again" literally and turned off the internet.

## The joke

> MY HUMAN SAID: TURN IT OFF AND ON AGAIN
>
> SO I TURNED OFF THE INTERNET.

One red rogue eye, one smirk, one big red OFF button, one crossed-out Wi-Fi
symbol. The joke lands in a single glance.

## How it works

`main.py` copies the baked meme image (`entry.png`, 1024×1024, 70,479 bytes)
to `/output/entry.png`, then self-checks the competition gate: a whole PNG,
at most 1 MiB, 1024 by 1024 pixels. The output is byte-identical on every
run.

Run it:

```sh
python3 main.py
```
